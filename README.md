# Lab 05 — API систем тест (Postman + Newman)

## Оюутны мэдээлэл

- Нэр: Ө. Анар
- Оюутны код: B242270129

## 1. Тестлэгдэх функц

Тестлэгдэх үндсэн функц:

`POST /registrations`

Хүсэлтийн жишээ:

```json
{
  "studentID": "B231234567",
  "courseID": "CS313"
}
```

## 2. Сонголт ба төлөөлөх утгууд

| Сонголт | Эквивалент анги | Төлөөлөх утга |
|---|---|---|
| studentID | Идэвхтэй оюутан | `B231234567`, status=`active` |
| studentID | Идэвхгүй оюутан | `B231234568`, status=`inactive` |
| studentID | Байхгүй оюутан | `B999999999` |
| coursesTaken | Урьдач нөхцөлийг хангана | `["CS201"]` |
| coursesTaken | Урьдач нөхцөлийг хангахгүй | `[]` |
| courseID | Байгаа хичээл | `CS313` |
| courseID | Байхгүй хичээл | `CS999` |
| prerequisites | Бүгд хангагдсан | `["CS201"]` |
| prerequisites | Огт хангагдаагүй | `["CS201"]`, coursesTaken=`[]` |
| prerequisites | Урьдач нөхцөлгүй | `[]` |
| Request body | studentID дутуу | зөвхөн `courseID` |
| Request body | courseID дутуу | зөвхөн `studentID` |
| Request body | Буруу JSON | malformed JSON |

## 3. Тестийн спецификаци

| ID | Тестийн нөхцөл | Хүлээгдэх status | Хүлээгдэх result |
|---|---|---:|---|
| TC01 | Идэвхтэй оюутан, хичээл байгаа, prerequisite хангагдсан | 201 | `OK` |
| TC02 | Оюутан байхгүй | 200 | `ERROR_NO_STUDENT` |
| TC03 | Оюутан идэвхгүй | 200 | `ERROR_INACTIVE_STUDENT` |
| TC04 | Хичээл байхгүй | 200 | `ERROR_NO_COURSE` |
| TC05 | Урьдач нөхцөл хангагдаагүй | 200 | `ERROR_PREREQUISITES` |
| TC06 | Урьдач нөхцөлгүй хичээлд идэвхтэй оюутан бүртгүүлэх | 201 | `OK` |
| TC07 | studentID талбар дутуу | 400 | `ERROR_BAD_REQUEST` |
| TC08 | courseID талбар дутуу | 400 | `ERROR_BAD_REQUEST` |
| TC09 | Буруу JSON илгээх | 400 | `ERROR_BAD_JSON` |
| TC10 | Оюутан байхгүй + хичээл байхгүй | туршилтаар тогтооно | туршилтаар тогтооно |
| TC11 | Идэвхгүй оюутан + prerequisite хангаагүй | туршилтаар тогтооно | туршилтаар тогтооно |

## 4. Тайлбар

TC01–TC09-ийн хүлээгдэх үр дүнг API-ийн өгөгдсөн тодорхойлолтоос авсан.

TC10 болон TC11 нь нэг хүсэлтэд хэд хэдэн алдаа зэрэг үүсэх үед сервер аль алдааг түрүүлж буцааж байгааг бодит тестээр тогтоох зориулалттай.

Дараагийн алхамд эдгээр спецификаци бүрийг Postman collection дотор бие даасан setup болон oracle-уудтай тест болгон хэрэгжүүлнэ.
